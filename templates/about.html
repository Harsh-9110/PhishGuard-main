HOW IT WORKS

Signals, then a decision.

PhishGuard combines URL classification with observable page warnings.

Three real models

Decision Tree, Random Forest, and scikit-learn Gradient Boosting are trained offline. The ensemble method is selected using grouped cross-validation. The last model is a compatible replacement for the original project's unavailable XGBoost dependency; it is not XGBoost.

Separate page evidence

Password forms posting to another hostname trigger a warning, even when the URL models give a low score. This can also occur with legitimate single sign-on. Keyword and HTML checks are rules, not a trained content model.

Understand the limits

The labeled dataset is from 2020. Scores are uncalibrated estimates and can produce false positives and false negatives. A lower-risk verdict is not permission to trust a site. Redirect destinations are fetched with the same network protections as the original URL.
